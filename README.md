# AI Resume Screening System 📄🤖

An interactive web application built with Python and Streamlit to help analyze resumes and extract relevant information from uploaded documents.

## Features

* Upload and process resumes in supported document formats.
* Extract text from PDF and DOCX files.
* Analyze resume content.
* Organize extracted information for easier review.
* Simple and user-friendly interface.

## Technologies Used

* Python
* Streamlit
* Pandas
* PyMuPDF
* Python-docx

## Installation

1. Clone or download this repository.

2. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Start the application:

   ```bash
   streamlit run app.py
   ```

   Replace `app.py` with your main Python filename if it is different.

## Purpose

This project demonstrates how Python and document-processing libraries can be used to extract and organize information from resumes through a web interface.
